# EONGROUP

Premium website design studio marketing site — a self-contained, static two-page site (no build step, no dependencies).

## Pages

- `index.html` — homepage (hero, services, work, process, pricing, why us, FAQ, final CTA)
- `book-consultation.html` — consultation request page with a form (submits via [Formspree](https://formspree.io))

## Running locally

These are plain static HTML files with all assets (fonts, video, images) embedded inline — just open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```
npx serve .
```

## Deploying

Works as-is on GitHub Pages, Netlify, Vercel, or any static host — just publish this folder.
